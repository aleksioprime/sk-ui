# sk-ui

Общие компоненты интерфейса школьных сервисов гимназии (Конкурсы, Опросы, Диагностика) на Vue 3 и Tailwind 4:

- элементы формы и раскладки: `UiButton`, `UiInput`, `UiSwitch`, `UiSelect` (свой выпадающий список с поиском и выбором
  нескольких), `UiDialog` (модальная форма), `UiConfirm` (модальное подтверждение), `UiCard`, `UiBadge`, `UiCopyField`;
- заглушки загрузки: `UiSkeleton`, `SkeletonTable`, `SkeletonList`, `SkeletonPage`;
- бренд гимназии: `BrandMark` (логотип и название сервиса в шапке и на странице входа), `SchoolFooter`
  (ссылка на хаб skolhub.ru и сайт гимназии), `createBrand` для заголовков вкладок;
- `OverflowNav`: меню шапки, лишние пункты уходят в «Ещё», на узких экранах (меньше `sm`) бургер у правого края
  с пунктами и слотом `burger-footer` для блока пользователя;
- `http`: клиент axios под контракт sk-common (продление сессии по 401, `errorMessage`);
- `base.css`: шрифт Golos Text, радиусы, фокус, курсор у кликабельного, единый вид полей и флажков.

Сервисы подключают пакет одинаково, поэтому кнопка, поле или футер правятся один раз.
Палитра у каждого сервиса своя: компоненты ссылаются только на имена токенов.

## Подключение

`package.json` сервиса - архив тега с GitHub (git в образе не нужен):

```json
"sk-ui": "https://github.com/aleksioprime/sk-ui/archive/refs/tags/v0.1.9.tar.gz"
```

Пакет отдаёт исходники `.vue`, поэтому Vite не должен их предсобирать, а vitest должен
обрабатывать их как свой код:

```js
// vite.config.js
export default defineConfig({
  optimizeDeps: { exclude: ['sk-ui'] },
  test: { environment: 'jsdom', server: { deps: { inline: ['sk-ui'] } } },
})
```

### Стили

```css
/* src/styles/main.css */
@import 'tailwindcss';
@import 'sk-ui/base.css';

@theme {
  --color-brand-50: #f4f0ff;
  --color-brand-100: #e9e1ff;
  --color-brand-200: #d4c6fe;
  --color-brand-500: #7c3aed;
  --color-brand-600: #6d28d9;
  --color-brand-700: #5b21b6;
  --color-brand-900: #2e1065;

  --color-surface: #ffffff;
  --color-canvas: #f8f7fc;
  --color-line: #e4e0f0;
  --color-ink: #1d1a2b;
  --color-ink-muted: #5f5a75;
}
```

`base.css` объявляет `@source` на компоненты пакета, отдельно указывать `node_modules` не нужно.
Токены `--color-score-*` нужны только `UiBadge tone="score"` (Конкурсы). Шрифт подключает
`index.html` сервиса ссылкой на Google Fonts.

### Бренд

```js
// src/brand.js
import { createBrand } from 'sk-ui'
export const { SERVICE_NAME, SCHOOL, HUB, pageTitle } = createBrand('Конкурсы')

// src/main.js
import { skUi } from 'sk-ui'
import { SERVICE_NAME } from './brand'
createApp(App).use(skUi, { serviceName: SERVICE_NAME }).mount('#app')
```

`BrandMark` показывает логотип сервиса из бренда (по умолчанию `/favicon.svg` приложения,
иначе `createBrand('Конкурсы', { logo })`); логотип гимназии лежит в пакете.

### Компоненты

```vue
<script setup>
import { SkeletonTable, UiBadge, UiButton, UiCard, UiInput } from 'sk-ui'
</script>
```

### Переключатели

`UiSwitch` принимает булево значение через `v-model`, постоянную подпись через
`label` и необязательное пояснение через `hint`. Для действия с запросом
используйте `:model-value`, `@update:model-value` и `:loading`.
При ошибке вызывающий компонент может оставить прежнее значение и показать сообщение.

### Опасные действия

Для кнопки удаления на странице используйте `UiButton variant="danger-outline"`.
Красная рамка и светлый фон выделяют действие среди остальных кнопок.
Для окончательного подтверждения в диалоге используйте `variant="danger"`.

### Хлебные крошки

Передайте в `UiBreadcrumbs` массив `items` с подписями `label` и маршрутами `to`.
Последний элемент отмечает текущую страницу. Длинная цепочка переносится на узком экране.

### Ссылки и раскрывающиеся блоки

`UiCopyField` по умолчанию показывает адрес в поле. Режим `variant="link"`
показывает короткую ссылку с подписью `label` и отдельной кнопкой копирования.

```vue
<UiDisclosure>
  <UiDisclosureButton>Предпросмотр</UiDisclosureButton>
  <UiDisclosurePanel>Содержимое предпросмотра</UiDisclosurePanel>
</UiDisclosure>
```

При необходимости управляйте блоком через `v-model:open`. Кнопку и содержимое
можно разместить в разных частях одного `UiDisclosure`, как в таблице.
Панель раскрывается и сворачивается плавно и учитывает настройку уменьшения движения.

### Формы и таблицы

Применяйте класс `ui-changed` к изменённому полю, его обёртке или строке.
Для блока из нескольких полей добавьте постоянный класс `ui-change-group`,
чтобы внутренние отступы сохранялись до и после правки.
`UiFormActions` располагается внутри формы и передаёт событие `cancel`.
Показывайте панель, когда форма отличается от сохранённого состояния.

`UiTable` получает `columns` и `rows`. Для сортировки используйте
`v-model:sort` и сортируйте строки в вызывающем компоненте. Слот
`cell-{key}` настраивает ячейку, слот `details` раскрывает подробности
под строкой. Укажите `primary` для колонки с кнопкой раскрытия.

### Модальные формы

`UiDialog` открывается через `v-model:open` и получает заголовок через `title`.
Передайте форму и её кнопки в слот, укажите `autofocus` на первом поле.
При сохранении передайте `:busy="saving"`, чтобы Escape не закрывал окно.
Храните черновик и ошибки в вызывающем компоненте. Закрывайте окно после успешного
сохранения и обрабатывайте отмену через `v-model:open` или явную кнопку.

## Состояние экрана в URL

В сервисах на sk-ui сохраняйте в адресе состояние, на которое можно дать ссылку:
активную вкладку, выбранный сохранённый вопрос или раздел, фильтры из списка,
сортировку и номер страницы. Для самостоятельных экранов используйте маршруты,
для состояния внутри экрана — query-параметры Vue Router.

Вызовите `useUrlQuery` из `sk-ui` в компоненте. Он возвращает реактивный
`route` и функцию `setQuery(values, { replace })`. Функция сохраняет
текущий путь, фрагмент и остальные параметры. Чтобы убрать параметр,
передайте для него `undefined`.

- Читайте параметры при открытии ссылки и при изменении маршрута, в том числе по
  кнопкам браузера «Назад» и «Вперёд». Пропущенные и некорректные значения
  возвращают экран к обычным настройкам. Идентификаторы сверяйте с доступными
  пользователю данными. Адрес не даёт дополнительных прав.
- Для явного выбора используйте `router.push`, для исправления устаревшего
  адреса — `router.replace`. Сохраняйте остальные параметры и фрагмент.
  При изменении фильтра начинайте с первой страницы. Нумерация в URL начинается с 1.
- Поиск, в который можно ввести ФИО, email или другие персональные данные, держите
  в состоянии компонента вместе с его пагинацией. Там же храните черновики,
  массовый выбор строк и данные прохождения опроса или диагностики.
- При проверке откройте скопированный URL, обновите страницу, пройдите назад
  и вперёд, затем проверьте ссылку с некорректными значениями.

## Разработка

```
npm ci
npm run lint
npm test
```

Пакет вместе с сервисом: в `package.json` сервиса временно `"sk-ui": "file:../sk-ui"` и `npm install`;
перед слиянием вернуть архив тега.

## Версии

| Версия | Что изменилось |
|---|---|
| `v0.1.0` | компоненты, бренд, клиент API и базовые стили, вынесенные из Конкурсов, Опросов и Диагностики |
| `v0.1.1` | `UiInput` сжимается до ширины, заданной классом (например, `w-24`) |
| `v0.1.2` | `OverflowNav`: бургер на узких экранах, скрытый ряд измерения не расширяет страницу, «Ещё» не выходит за край экрана |
| `v0.1.3` | `OverflowNav`: бургер у правого края, слот `burger-footer` для блока пользователя, Escape возвращает фокус на кнопку |
| `v0.1.4` | `UiDialog`: модальные формы с управлением фокусом и блокировкой закрытия при сохранении |

Выпуск: поднять `version` в `package.json`, тег `vX.Y.Z`, затем в каждом сервисе новый адрес архива,
`npm install`, зелёные проверки, слияние. Сервисы обновляются по одному.
